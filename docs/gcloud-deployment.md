# Google Cloud VM Deployment Guide for LiteMind Media

This document outlines the process for deploying the LiteMind Media web application with Convex database to a Google Cloud Virtual Machine.

## Prerequisites

- Google Cloud VM with Ubuntu Linux
- At least 2 vCPUs and 8GB RAM (recommended)
- Domain name with DNS configured to point to your VM's IP address
- GitHub repository with your application code
